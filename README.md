\## About



AlgoVision is a full-stack web application designed to help computer science students, software engineering interview candidates, and educators master Data Structures and Algorithms through:



\- Interactive step-by-step visualizations of 30+ algorithms and data structures

\- Multi-language coding playground (Java, C++, Python, JavaScript)

\- Algorithm Performance Lab to benchmark and compare algorithms on real data

\- Quiz engine with timed interview mode and difficulty levels

\- Personal dashboard with progress tracking and streaks



\---



\## Features



\### Visualization Engine

\- Arrays, Linked Lists, Stacks, Queues, Trees, AVL Trees, Heaps, Tries, Graphs

\- Sorting: Bubble, Selection, Insertion, Merge, Quick, Heap

\- Graph algorithms: BFS, DFS, Dijkstra, A\*, Kruskal, Prim

\- Play, Pause, Step Forward, Step Backward, Speed Control

\- Side-by-side algorithm comparison

\- Time and space complexity analysis panel

\- Code viewer in Java, C++, Python, and JavaScript



\### Algorithm Performance Lab

\- Run multiple algorithms on the same input simultaneously

\- Measure execution time, comparisons, and swaps

\- Plot performance graphs as input size grows



\### Coding Playground

\- Monaco editor (same as VS Code)

\- Multi-language support with sandboxed execution

\- Test case runner with verdict feedback



\### Quiz and Interview Mode

\- Topic-specific and general CS question banks

\- Timed interview simulation mode

\- Difficulty levels: Beginner, Intermediate, Advanced



\### User Features

\- JWT authentication (register, login, refresh)

\- Personal dashboard with progress tracking

\- Bookmark favourite algorithms
